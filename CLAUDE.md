# Reglas para el asistente (Claude Code / Codex)

Proyecto: prototipo de trazabilidad histológica para el curso Sistema de Información Hospitalarios II (MIM 2026).
Entrega: 24 de noviembre de 2026. Basta con un prototipo de "nivel cero".

## Cómo trabajar conmigo
- Pregunta antes de ejecutar comandos, instalar paquetes o crear archivos.
- Avanza una etapa a la vez. Si propones un plan largo, ejecuta solo la primera etapa y espera mi visto bueno.
- Explica en 2–3 líneas por qué eliges cada tecnología o diseño.
- Si algo falla, explica la causa antes de corregir.
- Respuestas cortas y en español.
- Si parto de datos reales, usa solo los nombres de las columnas y genera individuos ficticios.
- Al cerrar cada sesión, recuérdame hacer commit en GitHub.

## Datos
- NUNCA uses datos reales (IDs, notas ni imágenes del laboratorio). Todo es ficticio.
- No leas ni modifiques nada fuera de la carpeta `prototipo/`. La app original (carpeta superior) no se toca.
